# 🤖 Projeto Android — HTML5 e CSS3

Projeto desenvolvido durante os estudos de HTML5 e CSS3 no curso do professor Gustavo Guanabara, do [Curso em Vídeo](https://www.youtube.com/@cursoemvideo).

O projeto consiste na criação de uma página temática sobre a história do mascote Android, apresentando sua origem, evolução e curiosidades por meio de uma interface desenvolvida com HTML5 e CSS3.

## 🎯 Objetivo do Projeto

Aplicar os conhecimentos adquiridos durante os estudos de desenvolvimento web, construindo uma página informativa com identidade visual própria.

O projeto tem como objetivo praticar a estruturação semântica do HTML5, a estilização com CSS3, a utilização de fontes personalizadas e a criação de layouts responsivos.

## 🛠️ Tecnologias Utilizadas

- **HTML5** — estruturação e organização semântica do conteúdo.
- **CSS3** — estilização, posicionamento de elementos e construção do layout.
- **Google Fonts** — utilização de fontes externas.
- **Fontes personalizadas** — incorporação de arquivos de fontes locais utilizando `@font-face`.
- **Git** — controle de versão do projeto.
- **GitHub Pages** — hospedagem gratuita da página.

## ✨ Recursos e Implementações

- Estruturação da página utilizando elementos semânticos do HTML5.
- Organização do conteúdo com `header`, `nav`, `main`, `article`, `aside` e `footer`.
- Criação de menus de navegação.
- Utilização de fontes personalizadas com `@font-face`.
- Incorporação de imagens e elementos visuais.
- Aplicação de gradientes, sombras e bordas arredondadas.
- Utilização de vídeos incorporados com `iframe`.
- Organização e estilização de listas e conteúdos informativos.
- Criação de layout adaptável a diferentes tamanhos de tela.
